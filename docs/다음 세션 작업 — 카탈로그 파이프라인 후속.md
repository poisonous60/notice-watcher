## 2. gate_rejected 오탐 — 영구 게이트 fix 후보 (가장 큰 자가 결함)

### 2a. RSS XML 응답 = "보드 아님" 오판 (`board_shape_check` gap)
대상: `ruliweb-news-1001 / pc-1003 / mobile-1004 / nintendo-300004 / steam-clientbeta-group` (5개).

원인: probe 가 입력 URL 자체가 RSS/Atom XML 응답이면 `feed_candidates` 안 채움 (`discover_feeds` 는 HTML `<link rel=alternate>` 만 봄). board_shape gate 의 `n_feed >= 1` 신호 빠짐. + `html_repeating_patterns` 도 XML 에서 0건 → gate 거부.

**영구 fix** (CLAUDE.md §8a):
- `probe/discover.py` — 입력 URL response content-type 이 `application/rss+xml` / `application/atom+xml` / `application/xml` + body 가 `<rss` / `<feed` / `<?xml` 로 시작하면 `feed_candidates` 에 입력 URL 자체 박음.
- 동시에 `engine/config_schema.py` 의 strategy enum 에 `"rss"` 추가 + `adapters/rss.py` 의 `GenericRssAdapter` (feedparser 기반) 새로 박기.
- `engine/recognizers/rss_feed.py` — content-type 보고 즉시 `{strategy:"handwritten", adapter:"GenericRssAdapter", kwargs:{url:...}}` 생성.

### 2b. SPA 게시판 = "보드 아님" 오판 (Heavy SPA gap)
대상: `ncsoft-lineagew / aion2 / tl / pearlabyss-bdo-kr / blizzard-news / smilegate-epicseven` (6개).

세부 원인 다양:
- aion2 / lineagew / tl (plaync.com) — Akamai 가 Playwright fingerprint 잡고 "일시적으로 페이지를 불러올 수 없습니다" 에러 셸 반환. 글 0건.
- blizzard-news — Playwright 정상, HTML 9 패턴 잡힘. but `_same_host` 0건 (뉴스 링크가 cousin subdomain 으로 감, e.g. `play.blizzard.com/news/...`).
- BDO KR — 검증 필요 (probe artifact 확인).
- epicseven — `_single_article_nav_only_check`. nav 안 사이드바만 잡힘.

**영구 fix 후보**:
- `_board_shape_check` 가 cousin-subdomain 신호 허용 (apex domain 매칭? e.g. `*.blizzard.com`).
- `engine/recognizers/plaync.py` 추가 — `*.plaync.com/.../board/notice/list` 매칭 → `api.plaync.com` JSON API 직접 호출 config (`httpx_json`). aion2/lineagew/tl 일괄.
- Playwright fingerprint 강화 (stealth plugin) — Akamai 우회. **but CLAUDE.md 와 docs/크롤링 지침.md 가 우회 금지** — 정책 검토 필요.

### 2c. SPA + Cross-subdomain 신호 (`_same_host` 너무 엄격)
별 카테고리. blizzard-news 가 대표 케이스. apex-domain or registrable-domain 기준으로 완화 검토.
