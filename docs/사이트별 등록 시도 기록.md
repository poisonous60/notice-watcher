# 사이트별 등록 시도 기록

각 사이트 URL 을 `register.py` / 봇 `/watch` 로 등록 **시도한 결과**를 한 줄씩 적는 살아있는 로그.
새 사이트 등록을 시도할 때마다(특히 실패했을 때) **여기에 항목 추가** — *왜* 실패했고, 어떻게 해결했나(또는 못 했나).

- 실패 케이스 *분류*와 일반 대응 → `config 자동생성 실패 케이스.md`
- 지금 *작동 중인* 등록 사이트 목록(자동 파생) → `python scripts/register.py --list` (또는 `--list --csv`) — 그건 손으로 안 적음.
- 여기는 그것과 별개로, *사람이 적는 사례 + 판단 + 해결 메모* (자동 파생 불가한 지식).
- 상태 표기: ✅ 자동등록(작동중) / 🔧 손작성 config(작동중) / 🧩 손어댑터(작동중) / ❌ FAILED(미해결) / 🚫 등록 거부(정책)

---

### `mabinogimobile.nexon.com_News_notice` — https://mabinogimobile.nexon.com/News/notice
- **상태**: 🔧 손작성 config (작동중, baseline 10)
- **자동 등록 실패 원인** (2026-05-11): `[FAIL] article_body_len: 0자` 반복. 목록은 정적 HTML 로 잘 추출됨(제목·날짜·분류·URL). 문제는 글 본문 — 목록의 `<a href>` 가 `…/News/notice/View?threadId=3440249` 인데 그 URL 을 **직접 GET 하면 `/Main?aspxerrorpath=…` 으로 302 튕김**(= 클라이언트 사이드 라우트, 브라우저에서 목록 띄우고 클릭해야만 작동). 실제로 클릭하면 가는 주소는 `…/News/Notice/3440249` (경로형) — 이건 직접 GET 시 200 + 본문이 정적 HTML(`div.content_area`)에 들어있음. 자동 파이프라인은 페이지 HTML 어디에도 안 보이는 그 경로형 URL 을 추측할 방법이 없어서 실패 (글페이지 render+HAR re-probe 도 잘못된 `?threadId=` URL 을 열어서 `/Main` 만 렌더, 본문 없음). → `config 자동생성 실패 케이스.md` §2b(iii).
- **해결**: 손작성 `configs/mabinogimobile.nexon.com_News_notice.json` — `list` 는 자동 생성된 것과 거의 동일, `url` 필드만 `{from:"template", value:"https://mabinogimobile.nexon.com/News/Notice/{post_id}"}` (`post_id`=`data-threadid` attr 에서), `article.url_template` 도 경로형, `article.content`=`[div.content_area, section.view_body_wrap]`. `register.py --config configs/mabinogimobile.nexon.com_News_notice.json` 로 등록. 본문 fetch 1500자 확인됨.

### `cafe.naver.com_f-e_cafes_30291108_menus_6_viewType_L` — https://cafe.naver.com/f-e/cafes/30291108/menus/6?viewType=L
- **상태**: ❌ FAILED (미해결, 2026-05-11)
- **실패 원인**: `[FAIL] posts_nonempty: 0건` — 목록 추출이 0건. probe 가 글이 있는 건 알지만(first_article_url 잡힘) Gemini 의 `row_selector` 가 아무것도 못 잡음. **네이버 카페는 글 목록이 JS/iframe/내부 API 로 렌더**돼서 정적 HTML 에 글 행이 없음. → `config 자동생성 실패 케이스.md` §2a.
- **해결 방안 (미적용)**: `adapters/` 에 `NaverCafeAdapter`(handwritten) 가 있음 — `strategy:"handwritten"`, `adapter:"NaverCafeAdapter"`, `kwargs` 로 cafe id/menu id 지정하는 config 손작성 → `register.py --config`. (네이버 카페는 비공개판이면 로그인도 필요할 수 있음. 공개판이면 어댑터로 됨.) 필요해지면 진행.
